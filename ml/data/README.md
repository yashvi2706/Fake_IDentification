# ML Data

This directory contains scripts for generating synthetic datasets and managing sample data for training the AI modules.

## Planned Contents
- **Synthetic Generator:** Scripts to generate fake passport/visa/ID images and programmatically tamper them (swap photos, edit text fields, etc.).
- **Sample Data:** Placeholders for generated authentic vs. tampered datasets.

(Note: All data used here must be entirely fictional/synthetic. Never use real people's government ID data.)
